# /v1/place contract fixtures

Request/response pairs for `POST /v1/place` (ADR-0003 section 3). Each file is a
`PlaceContractFixture` (`packages/shared/src/placement.ts`).

Consumers:

- Jest (`backend/src/scheduler/io/placement-contract.spec.ts`): the frozen TS heuristic must match
  every `heuristic` pick, and each `request` must type-check as a `PlaceRequest`.
- pytest (`services/bandit`): `POST /v1/place` with `request` must return `response`, ignoring the
  fields in `ignore` (`paramsVersion`, `timingsMs`).

Heuristic fixtures are hand-checked (see each `description`). LinUCB, pairwise (`computeBoth`,
including the #58 pairwise-sampled series `series-pairwise-*`), cold-bandit and displacement
fixtures are generated by `services/bandit/scripts/gen_place_fixtures.py`.
