Login — 2-stage OTP

Passwordless email + one-time-password sign-in (CLAUDE.md §7 — OTP, no JWT). Mirrors frontend/src/pages/login.tsx + components/auth/login-form.tsx, rebuilt full-screen for touch. Stage 1 collects the email; stage 2 auto-submits on the 6th digit.

← All mobile mockups

Stage 1 — Email

Request an OTP. onBlur validation; the button shows a spinner while the code is sent. A 429 from POST /auth/otp/request (per-IP: 5/60s, per-email: 3/15min — LimitKit, #14) disables the field + button behind a live countdown until the window clears.

Stage 2 — One-time password

6-digit code; auto-submits on the final digit (onComplete). "Change email" returns to stage 1; "Resend code" re-requests through the same rate-limited endpoint, so it also starts a client-side cooldown. A 429 from POST /auth/otp/verify (per-IP: 20/60s, per-email: 10/10min — LimitKit, #14) freezes the code inputs and resend behind a countdown instead of allowing further guesses.
