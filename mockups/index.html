Built with Tailwind v4 installed as an npm package (the mobile-mockups pnpm workspace member) and compiled with the Tailwind CLI — no browser CDN, no inline @theme block. The design tokens (ported verbatim from frontend/src/index.css) and a small set of reusable component classes live in src/input.css; screen content is plain Tailwind utility classes in the markup so it maps cleanly to future NativeWind class names. Run pnpm --filter mobile-mockups build once (or pnpm --filter mobile-mockups watch while iterating) to produce dist/output.css, then open any HTML file directly. Frame: iPhone 15 Pro (393×852pt), Dynamic Island, 64dp/hr calendar grid. See docs/react-native-migration.md §"Figma Design Scope" for the full screen + micro-state inventory these implement.
