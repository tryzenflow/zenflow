Task sheets — native bottom sheets

Every Radix Dialog becomes a @gorhom/bottom-sheet slide-up over a dimmed calendar (migration doc Phase 5). Ports frontend/src/components/tasks/create-task-dialog.tsx + edit-task-dialog.tsx + use-task-form.ts; fields match the zod schema in frontend/src/utils/tasks.ts (title · duration 15-min steps · deadline · tags · note). Duration uses a thumb-friendly stepper/slider instead of the web's drag handles; placement is fully automatic, and an unplaceable task surfaces as a non-blocking conflict toast, not a blocking decision sheet. Description drops the web's docked toolbar for a selection bubble that floats above text you've selected instead — same full tool set as components/common/editor/toolbar.tsx (Bold · Italic · Underline · Highlight · Blockquote · Link · file upload · Bullets · Numbering), see the "Edit · populated" frame below.
