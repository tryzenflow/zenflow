Onboarding — first-run setup

Issue #88. Shown once after the first successful login, gated by a server-side User.onboardedAt. Six skippable steps, each writing through the existing user preference API: Name · DLU account · Notifications · Timezone · Default reminder · Tags. The language (default Tiếng Việt) is picked on the login screen, top right, so every screen already renders in it. Timezone defaults to the device zone with a full IANA search. Tags are new: a suggested set for students is pre-ticked and persisted as Tag rows (@@unique([userId, name])), so they appear in the task form’s Tags field. Skipped steps surface as a “Finish setting up” card in Settings. Back is available on every step except the first.
