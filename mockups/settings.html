Settings — home list + detail screens

Mirrors the real desktop frontend/src/components/settings/settings-dialog.tsx, which organizes preferences into exactly 4 tabs — Work (hours + days + timezone), Scheduling (duration-adjustment mode), Insights (preference heatmap + tag duration bias), Account (profile + sign out) — switched via a TabsList. There's no room for a horizontal tab bar with 4 dense panels on a phone, so the native pattern is two-level navigation instead: a Settings home screen showing just those 4 rows (icon + label + chevron-right), and a dedicated detail screen per section reached by tapping a row, each with its own back-chevron header. Row content within each detail screen still mirrors preferences-fields.tsx (work-hours TimeSelect, DAYS chips, timezone), duration-mode-field.tsx, and preferences.tsx's UserPreferencesPanel. Per migration doc Phase 5 → app/(app)/settings.tsx.

Pickers — bottom sheets

Tapping any row with a chevron (Start/End, Timezone, Duration adjustments, Profile) inside a detail screen slides up a @gorhom/bottom-sheet over the dimmed screen — same overlay/sheet chrome as task-sheets.html's create/edit sheets, not the OS-native picker. The selected option gets a tinted border + checkmark; the duration-mode sheet ports the three cards straight from duration-mode-field.tsx (icon, name, blurb). The profile sheet's Email field is locked — there's no PATCH /users/me for it yet, and email doubles as the OTP sign-in identity — only Name is editable.
