Connect your DLU account

Mobile-only (docs/thesis-scope.md §3.2, issue #26) — the credential hand-off that lets Zenflow's background watcher see a DLU student's LMS/portal. Reached by tapping the new "Connect your DLU account" row in Settings → Account, styled as a pushed screen with a back-chevron header (the same header pattern the old two-level Settings nav used, now legitimately reused here since this is a real navigation push, unlike settings' own flat sections). Zenflow never re-displays a saved password — after a successful save the field only ever shows empty/masked. LMS and Portal don't share a login, so each is modeled as its own credential pair (student ID + password) with its own connect/test/edit/disconnect lifecycle, independent of the other — adjust if the backend issue lands on a different shape.

Credential form

LMS and the student portal are separate logins, so each gets its own card — its own student ID + password, and its own "Test & save" that verifies live against DLU before anything is stored. Each card carries its own empty → testing → error (specific, retryable) state, independent of the other — a frame below shows one provider succeeding while the other is still empty or failing.
