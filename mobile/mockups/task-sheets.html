Task sheets — native bottom sheets

Every Radix Dialog becomes a @gorhom/bottom-sheet slide-up over a dimmed calendar (migration doc Phase 5). Ports frontend/src/components/tasks/create-task-dialog.tsx + edit-task-dialog.tsx + use-task-form.ts; fields match the zod schema in frontend/src/utils/tasks.ts (title · duration 15-min steps · deadline · tags · note · fixed-time). The Fixed/Flexible toggle leads the form; duration uses a thumb-friendly stepper/slider instead of the web's drag handles; overflow options come from CreateTaskResponse.overflow.
