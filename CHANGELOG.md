# Changelog

Zenflow is in beta. Changelogs are generated by [changesets](https://github.com/changesets/changesets)
per package (`backend/`, `frontend/`, `mobile/`, `packages/*`); all of them share one version, and each
GitHub pre-release carries the matching notes. See [`docs/ops/releasing.md`](docs/ops/releasing.md).

History before the beta reset (v1.0.0 to v2.1.0) lives in git.
